Wisp 2.6.4 Lap review 3D test
Private build ID: lap-review-3d-20261006-01

This is a private test build, not a public release. It updates your existing
Wisp installation and keeps your settings, profiles, calibrations, runs and
clips. It is not a separate installation.

Changes
- Switch between the existing 2D lap map and a 3D view of recorded elevation.
- Rotate, tilt, roll, pan and zoom the 3D map; reset the camera at any time.
- Keep every existing map/graph channel, wheel selector, comparison, cursor,
  section analysis and graph shortcut. Add horsepower, torque and elevation.
- Read the color legend and the selected point's value next to the map.
- Show reported object contacts, possible impacts and saved manual markers.
- Save the current 2D or 3D map, including its legend, as a PNG image.

Controls
Drag: rotate. Shift-drag or right-drag: pan. Ctrl-drag: roll.
Scroll: zoom. Double-click or Reset view: restore the camera.
Click the line: select a point. Arrow keys: move along the lap.
Home/End: first/last point. Camera controls also provide axis sliders.

Suggested checks
1. Open an existing saved lap in Runs and expand Lap review.
2. Switch between 2D and 3D. Rotate and zoom, then reset the view.
3. Change channels and wheels. Select a point, compare Run B, select a section
   and open it in graphs. The selected point/section should stay consistent.
4. Mark a known contact, reopen the run and remove the marker.
5. Save a PNG in both modes. Check the current view, colors and legend.
6. Record a new lap on your usual Steam or Xbox PC installation. Object
   contacts use the same Data Out fields on both editions.

Contact coverage
Forza reports velocity loss and mass for breakable-object impacts. Those
appear as Object contact in new recordings. Possible contact is an estimate
from movement; it is not a verified wall/car collision. Old recordings did
not retain the object-impact fields. Mark known contacts where needed.

Saved-run compatibility
Existing saved runs remain readable and keep their original format. New runs
with object-contact telemetry use run format 3 and require this build or newer.
If you reinstall public 2.6.4, those new runs are kept on disk but cannot be
opened there. Return to this build to review them. Exported runs keep the same
version requirement.

The 3D line uses recorded world positions at equal scale on all axes. Its floor
projection is a visual reference, not a terrain model. Dense laps are simplified
for display while keeping original samples for analysis and cursor selection.
