Wisp 2.6.4 Lap review 3D test
Private build ID: lap-review-3d-20261006-06

This is a private test build, not a public release. It updates your existing
Wisp installation and keeps your settings, profiles, calibrations, runs and
clips. It is not a separate installation.

Choose Skip setup to test this private build without opening Forza. The skip
lasts for the current session and does not change your saved setup evidence.
Public releases keep the normal setup flow.

Changes
- Switch between the existing 2D lap map and a 3D view of recorded elevation.
- Rotate, tilt, roll, pan and zoom the 3D map; reset the camera at any time.
- Keep every existing map/graph channel, wheel selector, comparison, cursor,
  section analysis and graph shortcut. Add horsepower, torque and elevation.
- Read the color legend and the selected point's value next to the map.
- Show reported object contacts, possible impacts and saved manual markers.
- Save the current 2D or 3D map, including its legend, as a PNG image.
- Optionally compare two 3D laps in Shared space, using the same channel and
  color scale. Click a track to move closer; zoom back out to see both.
- Keep the lap-position slider above the map and batch drag updates to one
  per UI render cycle, preserving the final position when released.
- Use one page scrollbar for the comparison controls and lap review.
- Compare recorded tracks from different cars in Shared space. Timing and
  matched-section checks remain separate from visual comparison.
- Give the track more room with a taller automatic view and a draggable lower edge.
- Keep camera zoom steady while rotating either the shared overview or a focused lap.
- Choose Both, A or B beside Lap position to move paired or independent cursors.
- Use zoom, reset, Show both laps and Show contacts directly from the top toolbar.
- View the channel graph directly below the legend, with Lap settings and
  benchmark beneath it. Drag the clearly marked divider handle to resize the map.
- Use mouse camera gestures without manual angle sliders or a contact editor.
- Center the close icon in the A note from Views popup.

Controls
Lap position: Both moves paired cursors; A or B moves only that lap. Both uses
matched positions where available, otherwise relative recorded lap distance.
Relative progress does not establish a valid time delta or matched section.
Drag: rotate. Shift-drag or right-drag: pan. Ctrl-drag: roll.
Click the map before using scroll to zoom; otherwise the wheel scrolls the page.
Double-click or Reset camera: restore the workspace camera.
Drag Resize map on the divider to resize it. Focus the grip and use Up/Down to
adjust the height, or Home to restore automatic sizing.
Click the line: select a point. Arrow keys: move along the lap.
Home/End: first/last point.
Choose Run B using Compare above, or choose a reference in Lap settings and
benchmark, then enable Shared space in 3D. Both tracks remain in the same scene,
laid out side by side. With Shared space off, the original single-lap view remains.
Click a track to bring the camera toward it. Scroll back out, choose Show
both laps or press Escape to frame both again. Rotation and pan
gestures affect the shared camera. PNG saves the current camera view.
Each map shows its recorded and saved contact markers. Show contacts hides
or shows those markers; this view does not add or remove saved contacts.

Suggested checks
1. Open an existing saved lap in Runs and expand Lap review.
2. Switch between 2D and 3D. Rotate and zoom, then reset the view.
3. Change channels and wheels. Select a point, compare Run B, select a section
   and open it in graphs. The selected point/section should stay consistent.
4. Toggle Show contacts and check the recorded markers on each lap.
5. Save a PNG in both modes. Check the current view, colors and legend.
6. Record a new lap on your usual Steam or Xbox PC installation. Object
   contacts use the same Data Out fields on both editions.

Contact coverage
Forza reports velocity loss and mass for breakable-object impacts. Those
appear as Object contact in new recordings. Possible contact is an estimate
from movement; it is not a verified wall/car collision. Old recordings did
not retain the object-impact fields. Previously saved markers remain visible.

Saved-run compatibility
Existing saved runs remain readable and keep their original format. New runs
with object-contact telemetry use run format 3 and require this build or newer.
If you reinstall public 2.6.4, those new runs are kept on disk but cannot be
opened there. Return to this build to review them. Exported runs keep the same
version requirement.

The 3D line uses recorded world positions at equal scale on all axes. Its floor
projection is a visual reference, not a terrain model. Dense laps are simplified
for display while keeping original samples for analysis and cursor selection.
