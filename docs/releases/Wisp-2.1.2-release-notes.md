# Wisp 2.1.2

A small performance hotfix for colored boost pressure numbers.

- Reuse digit images as boost colors and pulse opacity change, preventing cached images from accumulating throughout a session.
- Preserve the existing digit colors, shadows, sizing and needle behavior. Saved settings, profiles, tire calibration and runs are unchanged.

[Wisp 2.1.1 feature notes](https://github.com/Views2k/Wisp/blob/v2.1.1/docs/releases/Wisp-2.1.1-release-notes.md).
