# Wisp 2.1.2

A small performance hotfix for colored boost pressure numbers.

- Wisp reuses digit images as boost colors and pulse opacity change, preventing cached images from accumulating throughout a session.
- Digit colors, shadows, sizing and needle behavior are unchanged, along with saved settings, profiles, tire calibration and runs.

[Wisp 2.1.1 feature notes](https://github.com/Views2k/Wisp/blob/v2.1.1/docs/releases/Wisp-2.1.1-release-notes.md).
