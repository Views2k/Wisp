# Wisp 2.6.1

[Download Wisp 2.6.1 for Windows](https://github.com/Views2k/Wisp/releases/download/v2.6.1/Wisp-Setup-2.6.1.exe)

## Fixes and improvements

- Fixed an issue that could prevent the Tune viewer from working for some users.
- Fixed clipping requiring a Wisp restart after closing Forza.
- Fixed audio glitches clearing recorded clip history.
- Improved HDR recording and playback colors, and added optional HDR recording on supported NVIDIA hardware.
- Fixed issues that could interrupt lossless playback or prevent clip exports. Added compatible MP4 exports for easier sharing.
- Clips can now prepare for playback without closing Forza. Added loading progress and kept playback disabled while loading.
- Fixed deleted clips remaining in the gallery after refreshing.
- Added dismiss and **Don't show again** options for clip reminders, while keeping recording errors visible.
- Fixed a crash when using arrow keys in an empty lap review.
- Added clearer error messages and copyable crash, Tune and export details to help diagnose problems.
