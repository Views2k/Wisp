# Wisp 2.5.3

I fixed first-time HUD placement on systems with multiple monitors. Wisp now puts a HUD without a saved position on Forza's monitor when the game is detected, instead of keeping the temporary startup position on another screen.

If your gauge is already saved on the wrong screen, focus Forza once, then open Wisp and click **Reset HUD positions**. This moves the main HUD to the game's monitor and restores its default position, including the default size for native gauges. You can also use **Edit HUD layout** to drag it where you want it.

Existing saved layouts stay where you placed them unless you move or reset them. Wisp does not continually move the HUD when the game changes screens.
