# Wisp 2.6.6

[Download the latest published Wisp release for Windows](https://github.com/Views2k/Wisp/releases/latest)

## News and feedback

- Send **Diagnostics**, **Suggestions** or **Feedback** from Extras. Review the exact message before sending, cancel before submission and keep the confirmation reference.
- One accepted message per day. Wisp shows when another can be sent.

## Automatic diagnostics

- Wisp now uses a live API for better diagnostic collection. Reports combine app health, performance measurements and configuration details to help investigate issues.
- Windows, graphics-driver, display and Wisp settings help identify patterns across affected setups. Failure reports include recent performance context.
- Activity summaries include session time, estimated distance, average speed and peak observed speed.

[Privacy details](https://wispoverlay.com/legal/#privacy).

## Developer updates

- **A note from Views**, news, known issues and troubleshooting refresh automatically.
- Temporary dashboard announcements share the existing banner space. When an announcement ends, the automatic update notice returns. Update controls are available in Extras.
- Improved spacing in the unexpected-shutdown notice.
