# Wisp 1.2.2

September 11, 2026

A small bug-fix and runtime maintenance update.

- Keeps the main Native HUD in place when the attached G-force meter is enabled
  or disabled.
- Updates the bundled .NET 8 runtime to 8.0.31.

Saved HUD placement and profiles are preserved. A HUD at the top screen edge
may move inward once to keep the G-force meter visible.

Install `Wisp-Setup-1.2.2.exe` over the current Wisp version to keep settings,
profiles, tire calibration and saved runs. Artwork and needle behavior are unchanged.
