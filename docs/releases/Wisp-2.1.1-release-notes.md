# Wisp 2.1.1

This update fixes supplementary gauge alignment and adds independent sizing controls.

- **Matching analogue dials:** boost, tire temperature, power, and torque have equal dial sizes at 100%. Their row and column centers stay aligned when you choose different sizes.
- **Separate size sliders:** adjust power and torque independently in **Appearance → Gauges → Engine output**. Boost and tire-temperature sizes now apply while attached to the speedometer as well as detached.
- **G-force meter size:** choose a uniform size from **50% to 200%** in **Appearance → Gauges**. It applies to attached, detached, and Combined layouts.
- **Consistent preview:** the Analogue preview uses the same supplementary gauge layout as the HUD, and previews follow the G-force size setting.
- **Saved choices stay with you:** existing sizes, HUD profiles, detached positions, tire calibration, and runs are preserved. The previous shared power/torque size supplies the initial value for each independent slider.

All Wisp 2.1 features remain available, including live BHP and torque, fixed ranges for each car, adjustable smoothing, and shared gauge colors. The bundled runtime remains .NET 8.0.31.
