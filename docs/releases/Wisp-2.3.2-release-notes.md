# Wisp 2.3.2

The Appearance preview now shows the standalone boost and tire-temperature gauges enabled in Minimal, Combined and Box layouts.

- Both app interfaces show your selected gauge colors, individual sizes and tire-gauge style.
- Previews scale to fit the available space, with speed text remaining visible when scaled down.
- In-game gauge behavior, Native previews, attachment preferences, profiles and recordings are unchanged.

Includes the [standalone gauge support from Wisp 2.3.1](https://github.com/Views2k/Wisp/blob/v2.3.1/docs/releases/Wisp-2.3.1-release-notes.md).
